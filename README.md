# FIELDS — サッカースクールの WordPress テーマ（サンプル）

架空のサッカースクール「FIELDS」のオリジナルテーマです。ポートフォリオ用のサンプルで、実在のスクールではありません。

## 特長

- **管理画面から更新できる**
  - クラス（対象・曜日と時間・会場・月謝・回数）は「クラス」の投稿で管理。**料金の表もクラスの月謝から自動で作る**ので、金額の入力は1か所だけ
  - よくある質問は「よくある質問」の投稿、お知らせは通常の投稿
  - トップの文章・特長・体験の流れ・アクセスは、トップページの編集画面にタブで分けた入力欄（ACF）
  - 申し込みフォームは Contact Form 7。「希望のクラス」の選択肢は、登録したクラスから自動で作る
- **入力欄が空でも崩れない**：空のときはテーマに入っている文章を表示する（ACF が無くても表示できる）
- **アクセシビリティ**：スマホのメニュー（`aria-expanded`）、自動で切り替わるスライダーの一時停止、コントラスト比 4.5:1 以上、動きを減らす設定・JavaScript が無いときも全部表示
- **SEO**：h1 は日本語のキャッチコピー、見出しの順番、meta description

## 構成

| 場所 | 内容 |
|---|---|
| `theme/` | テーマ本体（`wp-content/themes/fields` にマウントされる） |
| `theme/inc/` | 機能ごとの PHP（投稿タイプ・入力欄・CF7 の調整など） |
| `theme/template-parts/front/` | トップページのセクション |
| `mu-plugins/local-mail.php` | 手元の環境でだけ、メールを Mailpit に送る |
| `scripts/` | 初回のセットアップと、サンプルの内容 |

## 手元で動かす

Docker が必要です。

```shell
./scripts/setup.sh
```

- サイト：http://localhost:8080
- 管理画面：http://localhost:8080/wp-admin（`admin` / `password`。手元の環境専用）
- 送信されたメール：http://localhost:8025（Mailpit）

止めるとき：`docker compose down`（データも消すときは `docker compose down -v`）

## 公開するときの注意

- サンプルとして公開する場合は、Contact Form 7 のフォームの「その他の設定」に `demo_mode: on` を入れて、実際にはメールを送らないようにする
- 「設定 → 表示設定 → 検索エンジンでの表示」をオフ（noindex）のままにする
